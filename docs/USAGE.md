# 使用指南

**简体中文** · [English](USAGE.en.md)

[返回项目介绍](../README.md) · [开发指南](DEVELOPMENT.md)

应用目前使用中文界面，支持 Windows x64、一个活动媒体目录，以及中国省 / 市地图。在应用外新增、移动或删除媒体后，请刷新目录或重启应用以更新索引。

## 第一次使用

1. **导入地图数据**：在照片墙模式点击“导入地图数据”，导入省、市两份受校验的 GeoJSON（见[地图数据](#地图数据)）。两份均就绪后，才能进行 GPS 省市解析和使用照片墙。
2. **选择媒体目录**：点击“选择照片文件夹”，选择一个本机文件夹；应用会递归建立基础媒体索引，并渐进显示扫描结果。
3. **确认元数据建议**：扫描会在本机读取图片元数据。可以忽略本次 GPS 地址与拍摄时间建议、应用建议并覆盖已有地址，或选择“仅为缺少信息的照片补充”。手动修改过的拍摄时间不会被扫描覆盖。
4. **整理回忆**：在批注模式的明信片或批量修改视图中编辑地点、标签、拍摄时间与备注，并按文件夹、类型、地点或关键词筛选。
5. **生成照片墙**：切换省 / 市层级，调整密度、视口、地名和区域固定照片。省级视图需要省份标记，市级视图还需要城市标记。
6. **导出分享图**：从照片墙打开导出面板，确认版式后保存 PNG；导出内容不含操作控件。

也可以先进入批注模式浏览照片、编辑备注或手工标注地点，稍后再导入地图。

> [!NOTE]
> 缺少地图数据时，应用仍会在本机探测 EXIF、GPS 和拍摄时间，以建立统计并保存经确认的拍摄时间；它只是不把原始 GPS 解析成省市候选。解析出的经纬度不会写入 SQLite、设置、缓存或诊断日志，也不会作为界面字段传递。原图仍保留原有元数据，预览可能读取包含这些元数据的原文件。

## 媒体兼容性

| 类别 | 扩展名 | 当前行为 |
| --- | --- | --- |
| 普通图片 | `.jpg`、`.jpeg`、`.png`、`.heic`、`.heif`、`.avif` | 可进入批注；解码有效且有地点的普通照片可进入照片墙 |
| 普通视频 | `.mp4`、`.mov`、`.m4v` | 网格使用 Windows 缩略图提供器生成封面；明信片默认静音循环播放，可暂停、拖动进度和开关声音 |
| Apple Live Photo | 匹配的 JPG / HEIC + MOV | 合并为一个逻辑项；只有当前明信片加载动态内容；删除和重命名可能同时涉及两个源文件 |
| Android Motion Photo | 带有效 XMP 与真实尾部视频载荷的 JPG / HEIC / AVIF | 作为单文件实况；只有残留 XMP 而没有视频载荷时不会误判 |
| 导出图片 | `.png` | 导出 UI 固定为 PNG |

- HEIC / HEIF、AVIF 与视频封面能否解码，取决于当前 Windows / Electron 可用的系统媒体能力；失败时媒体仍保留在索引中并显示错误占位。
- 元数据读取层会尝试所有支持的图片格式，但现有回归证据主要覆盖 JPEG / PNG；不对所有 HEIC / AVIF 变体作兼容承诺。
- 不支持 RAW、GIF、WebP、独立音频或未列出的其他格式。

## 地图数据

安装包与便携包**不包含**用于省、市几何解析的两份 GeoJSON。应用中的地图数据入口会调用系统浏览器打开[天地图云中心行政区划下载页](https://cloudcenter.tianditu.gov.cn/administrativeDivision)，上游文件需从该入口自行取得。

**获取状态：2026-09-10 尚未完成从官方入口重新取得兼容文件的验证。** 当前不能保证新用户可下载到应用接受的精确版本；准备投入整理前，请先确认两份文件均能导入。来源与核验状态见 [ASSETS.md](../ASSETS.md#上游依据与核验状态)。

当前支持的版本由仓库中的 [map-data-manifest.json](../src/shared/map-data-manifest.json) 锁定；它是本项目的兼容性清单，不是上游的版本名称。导入时不按文件名判断，只接受以下精确字节：

| --- | --- | ---: | --- |
| 省份 | `china-provinces.geojson` | 1,698,398 bytes | `3af8294f9ad61cc2bf84c1bb7e4bbf86a6336c68d754b699a0e6ddc33ef81486` |
| 城市 | `china-city-view.geojson` | 4,265,699 bytes | `d7a6f05b7e58cf758d74bd71ed0ea2ce981ef99436e4881e9a68098c3cd80b3b` |

### 下载与导入

1. 打开上述官方入口，查看适用条款，取得省、市两份 GeoJSON。当前兼容性清单只接受上表中的精确版本；官方更新后的文件可能不匹配。请先校验文件，再尝试导入。
2. 保留下载后的原始字节，不要使用编辑器格式化、改编码或重新保存。应用不要求改成上表中的规范文件名。
3. 可以直接在应用中导入，由应用核验；也可在 PowerShell 中运行 `Get-Item -LiteralPath '实际文件路径' | Select-Object Length` 和 `Get-FileHash -LiteralPath '实际文件路径' -Algorithm SHA256`，与上表核对。
4. 在地图数据入口选择省、市文件，可以一次选择两份，也可以分次导入。两份均导入成功后，再选择媒体目录扫描并确认地点建议；如果此前已扫描过目录，导入完成后按界面提示确认重新扫描的结果。

如果无法取得匹配版本，仍可浏览照片、编辑备注与手工标注地点；照片墙和 GPS 省市解析暂不可用。请通过 Issue 提供应用版本、官方来源页面、文件大小和 SHA-256，请求维护者核验新版本，无需上传地图本体或私人照片。改文件名不能解决哈希不匹配，重新下载到的新版也不一定兼容。

上游文件更新需由维护者核实来源条款、区域编码与地图行为，再更新兼容性清单和行政区目录；当前不支持任意 GeoJSON。数据来源记录见 [ASSETS.md](../ASSETS.md)。

### 校验边界

- 省、市可分两次导入；两份都通过校验后，照片墙和 GPS → 省市解析才完整启用。
- 错误、截断、不可读或哈希不匹配的文件不会被复制。上游即使发布语义等价的新文件，只要字节变化也会被拒绝。
- 随应用提供的轻量行政区目录只用于筛选、显示和手工批注，不包含地图几何；维护者生成与校验方法见[开发指南](DEVELOPMENT.md)。

## 数据、隐私与原文件安全

### 运行时网络边界

- 扫描、元数据读取、索引、筛选、缩略图和导出都在本机完成；没有账号、云同步或遥测。
- 打包应用的 renderer 会阻断 HTTP(S) / WebSocket 请求并拒绝权限请求、弹窗和跨页面导航。
- 用户点击地图数据下载入口时，主进程会显式打开系统浏览器；这是运行期唯一设计内的外部网页动作。

### 本地保存什么

媒体根路径与相对路径、文件哈希 / 大小 / 时间、媒体类型和状态、用户标签与备注、拍摄时间、经用户确认后的派生省市、设置、缩略图缓存及有限的诊断计数。

- 解析出的 GPS / 经纬度不会写入应用数据，也不会作为界面字段传递；原图仍保留原有元数据，预览可能读取包含这些元数据的原文件。
- 诊断日志不记录完整路径、标签内容、原始 EXIF / GPS 或经纬度。
- 没有应用级数据加密；能访问对应 Windows 账户数据目录的人可能读取这些数据。
- 用户选择的媒体目录不会收到索引、缩略图或旁车文件。

### 数据位置

| 交付方式 | 应用状态 | 导入地图数据 |
| --- | --- | --- |
| Squirrel 安装版 | `%LOCALAPPDATA%\PhotoMap\` | `%LOCALAPPDATA%\PhotoMapData\data\map-data\v1\` |
| 显式便携版 | `<EXE 所在目录>\PhotoMapData\` | `<EXE 所在目录>\PhotoMapData\data\map-data\v1\` |

便携模式只在 `PhotoMap.exe` 同级存在普通文件 `photomap.portable` 时启用。它会把 Electron 的 `userData`、`sessionData`、`logs`、`temp` 和 `crashDumps` 全部重定向到便携数据目录；目录不可写时应用会拒绝启动，不会静默回退到 C 盘。

### 便携版分享与备份

分享软件时，请使用尚未运行过、且不含 `PhotoMapData` 的干净便携包，并保留整个应用文件夹。使用后的 `PhotoMapData` 可能含有个人路径、标签、备注、缩略图和自行导入的地图数据，不应随软件一起分享。

备份自己的整理记录时，先退出应用，再备份完整便携文件夹并保留其中的 `PhotoMapData`。源媒体需要另行备份；应用只索引所选目录，不会自动将源照片复制进便携包。

### 哪些操作会改动源文件

| 操作 | 是否改动源文件 | 说明 |
| --- | --- | --- |
| 扫描、批注、筛选、生成缩略图 | 否 | 只读源媒体；整理记录和缓存写入应用数据目录 |
| 导出 | **取决于保存路径** | 写入用户选择的路径；如果选择已有的源 PNG 并确认覆盖，会替换原图，请使用新的文件名或单独的导出目录 |
| 重命名 | **是** | 只允许在原文件夹内改名且必须保留扩展名；实况多文件重命名若回滚也失败，会明确报告部分完成状态 |
| 确认删除 | **是** | 移入 Windows 回收站，不永久删除、不清空回收站；Apple 实况会尝试同时移动静态照片和伴随 MOV |

删除前会检查源文件是否仍与扫描记录一致；文件被外部改动时应先刷新再确认。实况照片的两个文件不能保证同时成功：若视频已移入回收站而照片失败，界面会提示部分完成，剩余照片保留在列表中，可解除占用后重试。已移走的视频可从 Windows 回收站恢复；需要恢复实况配对时，恢复原文件后刷新媒体目录。
